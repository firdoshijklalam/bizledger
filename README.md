# BizLedger — Digital Khata for Modern Business

Mobile-first business management platform for Indian traders. Built with Next.js 16, Prisma, Zustand, and Shadcn/UI.

## Quick Start
```bash
bun install
bun run db:push
bun run dev
```

Open http://localhost:3000 — demo data auto-seeds on first load.

## Documentation
See [HANDOVER.md](./HANDOVER.md) for complete project handover document.

## Tech Stack
- Next.js 16 (App Router + Turbopack)
- Prisma 6 (SQLite dev / Neon PG prod)
- Zustand 5 (state management)
- Shadcn/UI + Tailwind CSS 4
- Recharts (charts)
- Framer Motion (animations)
- z-ai-web-dev-sdk (AI/OCR)
- 3 languages: English, বাংলা, हिन्दी
